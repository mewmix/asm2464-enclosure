# CPU/CAD integration review artifacts

Generated from `model.py` and `hardware/rev-a/board.json` by `scripts/validate_twin.py`. STEP geometry and software renders are retained for this reviewed simulation milestone. `dimensions.json` and `cad-validation.json` record the shared board configuration hash.

The green/blue solids are board envelopes; service, shunt, chip and flash heights remain provisional. The metal insert has a lower locating flange and a modeled thermal pad path to the ASM envelope. This is not a completed PCB assembly or a fabrication release. See `validation/README.md` for unresolved gates.
